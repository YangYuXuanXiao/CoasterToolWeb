すべてのライドを記録し、体験をもう一度。

Coaster Tool は、iPhone と Apple Watch でジェットコースターの動きを記録するアプリです。荷重グラフ、校正、リプレイ、記録の比較、推定された 2D・3D 軌跡を確認できます。

お問い合わせ

以下の GitHub Issues から、端末名、OS とアプリのバージョン、問題の再現手順をお知らせください。Issue は公開されます。正確な位置情報、個人的な写真、記録データ全体をアップロードしないでください。

開発者に問い合わせる（公開 Issue）

画面ロック中の記録

モーションへのアクセス許可が必要です。位置情報の許可は任意です。位置情報を許可してアプリを前面で表示した状態で記録を開始すると、iPhone の画面をロックしたり別のアプリに切り替えたりしても記録を続けられます。その間、システムのバックグラウンド位置情報インジケータが表示されます。Apple Watch も位置情報を許可するとバックグラウンドで記録できます。許可しない場合、どちらの端末もバックグラウンドに移ると記録を停止して保存します。1 回の記録は最大 20 分です。

バックグラウンド記録はシステムの動作制御に従うため、欠測や終了が発生することがあります。iPhone でアプリを強制終了した場合やシステムがアプリを終了した場合、未保存の記録が失われることがあります。欠測したサンプルを作り出して補うことはありません。

iOS 17 以降、watchOS 10 以降に対応しています。iPhone のリアルタイム XYZ 表示には、端末の各軸に沿った未校正の荷重が表示され、Watch には生の合成荷重が表示されます。記録後に車両軸の荷重を表示するには、対応する校正が必要です。端末が対応していれば気圧と相対高度も記録します。気圧計が利用できなくても、ほかのセンサーの記録は続きます。

停止前の確認

停止確認は iPhone と Apple Watch で個別に設定でき、初期設定ではオフです。オンにすると停止時に確認が表示され、オフではすぐに記録を終了します。iPhone の「Apple Watch 設定と同期」から Watch 側の設定を変更することもできます。オフラインでの変更は接続後に同期され、記録中に受信した変更は次の記録から適用されます。設定を同期できるよう、両方のアプリを最新にしてください。

実際に記録せずに試す

「履歴」でデモ記録を読み込み、詳細を開くと、荷重グラフ、リプレイ、軌跡を試せます。デモのモーションデータは合成データであり、実測ではないことを明示しています。

校正と 2D・3D 軌跡

軌跡には、重力と進行方向の完全な校正、有効な地理的方位、同じ連続モーションデータ区間内で品質チェックに合格した GPS 観測が必要です。「範囲と校正」で新しい分析範囲を保存すると、2D・3D 共通の軌跡を再計算します。記録全体に範囲を戻して保存すれば、ライド全体を再計算できます。生のサンプルは保持されます。条件を満たさなくても記録や利用可能な荷重データの表示はできますが、慣性データのみ、または GPS のみの軌跡には切り替わりません。推定にはドリフトがあり、動きや装着状態に左右されます。アプリはライドの安全認証や専門的な工学測定を提供しません。

気圧高度は、その記録で最初に得られた有効な気圧サンプルを基準とする相対値です。GPS が品質チェックに合格した後、高度推定の補助に使われます。分析範囲をトリミングしても基準は変わりません。気圧計は GPS や地理的方位の代わりにはならず、単独で軌跡を生成することもできません。

ライド区間を自動トリミング

「範囲と校正」で「自動トリミング：巻き上げ・発進からブレーキまで」を選ぶと、巻き上げまたは発進から最後のブレーキまでの区間を提案します。アプリで収録した記録は XYZ 校正が完了している必要があります。検出に GPS は不要です。提案を調整するか記録全体に戻し、保存すると、統計、リプレイ、比較、書き出し、軌跡が更新されます。信頼できる区間を検出できない場合は現在の選択を保持し、手動で調整できます。4 配列形式の読み込みデータには傾斜情報がないため、滑らかな巻き上げ区間は手動で追加選択する必要がある場合があります。この形式のデータをトリミングしても軌跡は生成されません。

測定値を保ちながらグラフを滑らかに

アプリで収録した荷重のグラフは、短い孤立したスパイクや高周波の揺らぎを表示用に抑え、持続するピークや実際の欠測を保ちます。選択点、リプレイの数値、統計、CSV・JSON にはこの表示用フィルターをかけない測定値を使うため、描画された曲線と多少異なることがあります。校正用の生データグラフと、読み込んだ 4 配列の荷重には、この表示用フィルターをかけません。

転送とデータの保管

Watch の記録は WatchConnectivity を通じてペアリング済みの iPhone に転送されます。ローカル記録、写真、Watch 側の原本、受信箱、メモの下書きはシステムのデバイスバックアップから除外されます。通常の設定はバックアップされる場合があります。端末の移行や再インストール前に、メモを含まない iCloud バックアップを手動で作成するか、残したい記録を書き出してください。記録 JSON にはメモが含まれます。写真は別途保存する必要があります。

Watch は、iPhone が検証と保存を終えて受領通知を返した後にだけ「同期済み」と表示します。iPhone の保存件数が上限に達している場合も、受信箱のファイルと Watch 側の原本は保持され、Watch はオフラインで記録を続けられます。空きを作るか保存件数を増やした後、同期設定から再試行してください。

記録の保存件数と購入

iPhone には無料で 50 件の記録を保存できます。「設定」の「すべてのライドを残そう」から「記録の保存件数」を開くか、「履歴」の「記録の保存件数」で使用状況を確認できます。「100 件」の買い切り購入で上限が合計 100 件になり、「記録数無制限」で件数の上限を解除できます。どちらも非消耗型の買い切り購入で、サブスクリプションではありません。価格は App Store に表示されます。アップグレードは表示価格の全額を支払う別個の購入で、以前の購入額は差し引かれません。iCloud ストレージは増えず、20 分の記録上限やファイルサイズの上限も変わりません。

「記録の保存件数」は通常「履歴」の下部に表示され、使用率が 90%（50 件中 45 件、または 100 件中 90 件）になると上部に移動します。デモや端末に保持されている読み取り不能ファイルを含む、保存済みのローカル記録がすべて件数に数えられます。満杯の状態で新しく記録を始めると購入画面が開きます。既存の記録は引き続き表示、編集、書き出しができます。不要な記録を削除すると空きを作れます。

「記録の保存件数」の購入画面で「購入を復元」を選ぶと、現在の App Store アカウントで有効な保存件数の購入を復元できます。記録データの復元ではありません。有効な購入のうち最も高いプランが適用されます。返金や取り消し後は、残っている有効なプラン、または無料の 50 件に戻り、既存の記録は保持されます。iCloud の手動バックアップと復元は無料で利用できます。

購入が反映されない、承認待ち、返金された場合

購入後も保存件数が増えない場合は、購入に使った App Store アカウントでサインインしていることを確認し、アプリに戻るか「記録の保存件数」で「購入を復元」を選んでください。iCloud と App Store のアカウントは異なっていてもかまいません。購入の復元は有効な保存件数の利用権を戻す操作です。記録と写真は iCloud のスナップショットから別途復元してください。支払いが中断したりエラーが表示されたりした場合は、再購入する前に現在の利用権を確認してください。

承認待ちの間は保存件数は増えません。購入画面を閉じても、承認済みの取引を受信するとアプリが利用権を更新します。リクエストが却下されたり期限切れになったりした場合は、再試行するか決める前に状態を改めて確認してください。返金申請は Apple の返金手順に従ってください。承認は Apple が判断します。返金後は残っている有効なプランのうち最も高い保存件数が適用され、既存の記録は保持されます。

アプリの利用条件は Apple 標準エンドユーザ使用許諾契約（EULA）を、iCloud サービスのデータ処理は Apple Account と iCloud のプライバシー情報をご覧ください。

iCloud の手動バックアップと復元

「設定」から「記録のバックアップ」を開くと、手動スナップショットの一覧表示、作成、復元を無料で行えます。購入や購入の復元は必要ありません。バックアップは毎回自分で開始します。自動バックアップや双方向同期ではありません。自分の iCloud Drive ストレージを使うため、iCloud へのサインイン、iCloud Drive の有効化、十分な空き容量が必要です。

新しいスナップショットには、iPhone に保存済みの記録、正確な GPS、気圧データ、校正、写真が含まれます。すべてのメモ、設定、未同期の Watch ファイルは除外されます。ローカルのメモは残りますが、新しいスナップショットからは復元できません。端末の変更やアンインストール前に「iCloud にアップロード済み」と表示されていることを確認してください。システムによるアップロード待ちは、アップロード完了を意味しません。

復元するスナップショットを選んで確認します。この端末で削除されておらず、まだ存在しない記録だけが追加され、既存の編集は保持されます。復元時も現在の保存件数の上限が適用されます。追加対象の全件分の空きがなければ、1 件も読み込まれません。空きを作るか保存件数を増やしてから再試行してください。

バックアップは保存済みの全記録の完全な生サンプルを含み、選択中の記録や分析範囲だけには限定されません。分析範囲をトリミングしても、その範囲外の GPS やほかのサンプルはスナップショットから除去されません。Watch の記録を含めるには、先に iPhone への転送と保存を完了する必要があります。バックアップページを開くだけでは新しいスナップショットは作成されず、既存の一覧とアップロード状態が読み込まれます。

バックアップや復元が完了しない場合

iCloud にサインインし、iCloud Drive が有効であることを確認してください。ネットワーク、iCloud ストレージ、端末の空き容量も確認してください。アップロード待ちの状態では、完全なコピーが iCloud に存在するとは限りません。一覧を更新して確認できます。スナップショットをダウンロード中の場合は、完了を待ってもう一度タップして復元してください。iCloud アカウントを切り替えた後は、更新された一覧のスナップショットを確認してください。

利用可能な記録がない場合や、ローカル記録を読み取れない場合は、新しいスナップショットは作成されず、原本のファイルは保持されます。各スナップショットは最大 10,000 件・256 MiB、写真は 1 枚あたり最大 16 MiB です。記録数無制限の購入でも、この上限はなくなりません。大きな記録は 1 件ずつ JSON に書き出し、写真を別途保存できます。完全な記録 JSON は、現在、手動で再読み込みする機能がありません。

保存枠が足りない場合、復元では記録を追加しません。件数の確認を通過した後にディスクへの書き込みが中断すると、一部だけ復元済みになることがあります。復元済みの記録は保持されます。端末のストレージの問題を解決して再試行してください。再試行時は復元済みの記録をスキップし、重複作成や既存の編集の上書きをしません。

荷重 JSON の読み込み

「履歴」の「JSON を読み込む」またはシステムの「CoasterTool で開く」から、Vertical、Lateral、Longitudinal、Combined の 4 配列形式の荷重データを読み込めます。ファイルにはサンプルレートや乗車日時が含まれないため、保存前にプレビューしてサンプルレート（初期値 50 Hz）を確認してください。4 つの元のチャンネルをそのまま保持し、範囲選択、リプレイ、比較ができますが、再校正や軌跡の生成はできません。完全な CoasterTool 記録 JSON には現在、手動で再読み込みする機能がありません。アプリ内で記録と写真を復元するには iCloud スナップショットを使ってください。

書き出しとプライバシーの選択

PNG、CSV、4 配列 JSON には GPS 座標は含まれません。記録 JSON には生の位置情報、センサーデータ、校正、メモが含まれます。リプレイの写真はこれらの書き出しに含まれず、別途保存する必要があります。

コピーの管理

iPhone の記録と写真を削除しても、Watch 側の原本、書き出したファイル、iCloud スナップショットは削除されません。同期が成功しても Watch のファイルは自動削除されません。「ファイル」→「iCloud Drive」→「CoasterTool」→「Backups-v1」でクラウドのスナップショットを管理できます。アンインストールすると、その端末のローカルデータと削除マーカーが消去されます。対応している古いスナップショットは、再インストール後や新しい端末で手動復元できます。返金してもローカル記録や既存のスナップショットは削除されません。

古いスナップショットにはメモが含まれることがあります。自動的に変更や削除はされません。対応している古いスナップショットを復元するとメモも戻ることがありますが、新しく作るバックアップからは除外されます。不要な古いスナップショットは「ファイル」で確認して削除してください。

システムのデバイスバックアップからの除外は、現在のローカル保存に適用されます。以前に作成済みのシステムバックアップをさかのぼって消去するものではなく、古いバージョンで保存したメモの下書きが残っている可能性があります。そのようなバックアップはシステムのバックアップ管理機能で管理してください。

アトラクションのルールを守り、端末をしっかり固定し、乗車前に記録を開始してください。乗車中は操作しないでください。測定値からライドの安全性を判断することはできません。
