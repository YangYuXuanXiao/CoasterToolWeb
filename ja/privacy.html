プライバシーポリシー

このポリシーについて

2026 年 9 月 28 日更新。Coaster Tool 1.1 に適用されます。開発者：Yangyuxuan,Xiao。Coaster Tool 独自のアカウントは不要です。アプリはライドの記録と分析を行い、安全性の評価は提供しません。任意の購入とクラウドバックアップには、それぞれ App Store と iCloud のアカウントを使用します。

端末上で処理するデータ

アプリは端末上で、モーション、取得可能な気圧と相対高度、任意の正確な GPS 位置情報、タイムスタンプ、ライド名、パーク、座席、メモ、お気に入り、設定、選択した写真を処理します。システムの写真選択画面で選んだ写真だけをコピーします。コピーから元の EXIF・GPS メタデータを除去し、写真ライブラリの原本は変更しません。メモの下書きは、システムのデバイスバックアップから除外された専用のローカルディレクトリに保存します。アップデート時は、そこへの保存が成功した後にだけ、以前の設定領域にあるコピーを削除します。失敗時は原本を保持し、再試行を促すメッセージを表示します。通常の設定と、ライド名・パーク・座席の下書きはシステムのデバイスバックアップに含まれる場合があります。

Watch の転送とローカル保存

Watch の記録は WatchConnectivity を通じてペアリング済みの iPhone に転送されます。ローカル記録、写真、Watch 側の原本、受信箱、メモの下書きはシステムのデバイスバックアップから除外されます。通常の設定はバックアップされる場合があります。端末の移行や再インストール前に、メモを含まない iCloud バックアップを手動で作成するか、残したい記録を書き出してください。記録 JSON にはメモが含まれます。写真は別途保存する必要があります。

iCloud の手動バックアップと復元

iCloud の手動バックアップと復元は無料で、購入や購入の復元は不要です。「今すぐ iCloud にバックアップ」をタップしたときにだけ、この iPhone に保存済みの記録から独立したスナップショットを作成し、現在の iCloud アカウントに保存します。保存件数の購入、購入の復元、ページを開く操作で、記録が自動アップロードされることはありません。この機能は自動バックアップや双方向同期を行いません。

新しいスナップショットには、生のモーションサンプル、気圧と相対高度、正確な GPS 位置情報、タイムスタンプ、ライド名、パーク、座席、4 チャンネルの荷重、校正、分析範囲、お気に入り、写真が含まれます。重複を検出するため、記録 ID と Watch の元データのダイジェストも保持します。すべてのメモ、アプリ設定、未同期の Watch 記録、Watch 側の原本、受信箱は除外します。ローカルのメモは残りますが、新しいスナップショットからは復元できません。自分で書き出す記録 JSON には引き続きメモが含まれます。

バックアップには自分の iCloud Drive ストレージを使用し、保存と転送のサービスは Apple が提供します。開発者はユーザーの iCloud Drive にアクセスできません。iCloud へのサインイン、iCloud Drive の有効化、空き容量が必要です。アップロードの実行はシステムが管理し、iCloud Drive フォルダへのローカル書き込みだけではアップロード完了を確認できません。端末の変更やアプリのアンインストール前にクラウドの状態を確認してください。

復元するスナップショットは自分で選んで確認します。この端末で削除されておらず、まだ存在しない記録だけを追加し、既存の編集を保持します。未対応または破損したスナップショットは読み込まず、クラウドの原本も保持します。iCloud アカウントを切り替えると表示中の一覧がクリアされ、前の操作の結果はローカルに反映されません。

復元にはローカルの保存件数の上限が適用されます。追加対象の全件分の空きがなければ、1 件も追加しません。空きを作るか保存件数を増やして再試行できます。クラウドのスナップショットは変更されません。

バックアップは保存済みの全記録の完全な生サンプルを含み、選択中の記録や分析範囲だけには限定されません。分析範囲をトリミングしても、その範囲外の GPS やほかのサンプルはスナップショットから除去されません。Watch の記録を含めるには、先に iPhone への転送と保存を完了する必要があります。バックアップページを開くだけでは新しいスナップショットは作成されず、既存の一覧とアップロード状態が読み込まれます。

アプリ内課金と購入の復元

無料でローカルに保存できるのは 50 件です。Apple のアプリ内課金で上限を合計 100 件、または無制限に増やせます。保存件数の購入は非消耗型の買い切りで、サブスクリプションではありません。価格は App Store に表示されます。各プランは別個に課金され、アップグレードも表示価格の全額が必要です。以前の購入額は差し引かれません。iCloud のバックアップと復元は無料です。保存件数を購入しても iCloud ストレージは増えず、記録時間やファイルサイズの上限も変わりません。

支払いは Apple が処理します。アプリは端末上で StoreKit の商品情報、取引 ID、商品 ID、購入または取り消しの状態を使って保存件数の利用権を検証し、有効なうち最も高いプランを適用します。起動時、前面に戻ったとき、取引の更新時に利用権を確認します。「購入を復元」をタップしたときだけ購入の復元処理を開始し、App Store アカウントの認証が求められる場合があります。この処理でライドの記録、位置情報、写真を開発者へアップロードすることはありません。開発者は支払いカード情報や Apple Account のパスワードを受け取らず、取引を受信するサーバーも運用していません。

Apple は別途、アカウント、支払い、購入のデータを処理し、個人を直接特定しない購入・返金レポートを開発者に提供する場合があります。アプリを削除しても Apple の取引記録は消去されません。App Store とプライバシーをご覧ください。

購入の復元には「記録の保存件数」の購入画面で「購入を復元」を選びます。保存件数の利用権は購入に使った App Store アカウントに、バックアップは現在の iCloud アカウントに紐づきます。両者が異なっていてもかまいません。購入を復元しても記録の自動アップロードやバックアップの復元は行いません。返金や取り消し後は、残っている有効なプラン、または無料の 50 件に戻り、ローカル記録とクラウドのスナップショットは保持されます。既存の記録は引き続き表示、編集、書き出し、削除ができ、新しい記録には現在の上限が適用されます。

アプリの利用条件は Apple 標準エンドユーザ使用許諾契約（EULA）を、iCloud サービスのデータ処理は Apple Account と iCloud のプライバシー情報をご覧ください。

自分で管理する書き出しと共有

PNG、CSV、4 配列 JSON には GPS 座標は含まれません。記録 JSON には生の位置情報、センサーデータ、校正、メモが含まれます。リプレイの写真はこれらの書き出しに含まれず、別途保存する必要があります。

共有は自分で開始します。ファイルは選択したアプリや相手に送られ、書き出したコピーは自分で管理します。

保管と削除

ローカル記録は自分で削除するまで保存されます。iPhone の記録と写真を削除しても、Watch 側の原本、書き出したファイル、iCloud スナップショットは削除されません。同期が成功しても Watch のファイルは自動削除されません。端末からアプリを削除すると、その端末のローカルデータも削除されます。

手動バックアップはそれぞれ独立したスナップショットを保存します。ローカル記録の削除、アプリの終了、返金によってクラウドのコピーが削除されることはありません。「ファイル」→「iCloud Drive」→「CoasterTool」→「Backups-v1」でスナップショットを管理・削除できます。古いスナップショットにはメモが含まれることがあり、自動的に変更や削除はされません。対応している古いスナップショットを復元するとメモも戻ることがありますが、新しく作るバックアップからは除外されます。

ローカルの削除マーカーには記録 ID と、該当する場合は Watch の元データのダイジェストを保持し、遅れて届いた Watch 転送や復元操作で削除済み記録が再作成されるのを防ぎます。アンインストールするとマーカーは削除されるため、再インストール後や別の端末では古いスナップショットの記録を手動で復元できます。書き出したコピーは、ユーザーと選んだ共有相手が管理します。

システムのデバイスバックアップからの除外は、現在のローカル保存に適用されます。以前に作成済みのシステムバックアップをさかのぼって消去するものではなく、古いバージョンで保存したメモの下書きが残っている可能性があります。そのようなバックアップはシステムのバックアップ管理機能で管理してください。

アクセス許可と取り消し

モーションと位置情報の許可はシステム設定で変更できます。許可の取り消しや記録の停止では保存済みのコピーは削除されません。削除したい場合は該当する記録を削除してください。位置情報を許可し、アプリを前面で表示した状態で記録を開始すると、iPhone は画面ロック中やほかのアプリへの切り替え後もバックグラウンドで位置情報を使用し、システムの位置情報インジケータが表示されます。Watch も位置情報を許可するとバックグラウンドで記録できます。許可しなくても両端末で前面での記録はできますが、バックグラウンドに移ると停止して保存します。

サービス提供者

開発者はライドの記録を収集するサーバーを運用していません。アプリには広告、第三者の分析 SDK、ほかのアプリをまたぐトラッキングはありません。MapKit、App Store のアプリ内課金、任意の iCloud Drive サービスは Apple が提供し、関連データは Apple のプライバシーポリシーに従って扱われます。ウェブサイトは GitHub Pages で公開され、IP アドレスなどのリクエスト情報が処理される場合があります。サイトにアクセス解析スクリプトやトラッキング Cookie はありません。Apple と GitHub のプライバシー方針へのリンクは以下にあります。

このウェブサイトは、次回のアクセスのために、手動で選択した言語だけをブラウザのローカルストレージに保存します。「ブラウザの言語を使用」でこの設定を消去できます。トラッキングには使いません。

お問い合わせと更新

プライバシーについての質問は、GitHub Issues またはメールで開発者へお問い合わせください。アプリの使用に関する問題の場合は、Issue またはメールに、端末のモデル名、OS（iOS／watchOS）のバージョン、アプリのバージョン、問題の内容、期待する結果と実際の結果、問題を再現できる具体的な操作手順を記載してください。GitHub Issues は公開されます。どちらの方法でも、正確な位置情報、個人的な写真、生の記録データを添付しないでください。ポリシーを変更する場合は更新日を変更します。
