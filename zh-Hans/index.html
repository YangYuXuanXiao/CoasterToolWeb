Coaster Tool 用于 iPhone 与 Apple Watch 过山车运动记录。查看载荷曲线、校准、回放、对比和估算的 2D / 3D 轨迹。

开始录制与锁屏

运动权限用于录制，定位可选。在前台开始录制并授权定位后，iPhone 可在锁屏或切换 App 后继续录制，并显示系统后台定位指示；Apple Watch 授权定位后也支持后台录制。未授权定位时，两端进入后台都会结束并保存。单次最长 20 分钟。

后台录制仍受系统调度影响，可能出现缺测或被终止；iPhone 被强制退出或系统终止时，未保存的录制可能丢失。缺失采样不会被补造。

支持 iOS 17 及以上和 watchOS 10 及以上。iPhone 实时三轴显示未校准的设备载荷，Watch 显示原始合载荷；录制后的列车方向载荷需完成相应校准。设备可用时还会采集气压和相对高度，气压计不可用不影响其他传感器录制。

停止录制前确认

iPhone 与 Apple Watch 的停止录制前确认分别设置，默认关闭。开启后，点击结束录制需要再次确认；关闭时直接结束。手表设置也可在 iPhone 的“Apple Watch 设置与同步”页面修改；离线改动在连接后同步，录制期间收到的改动在下次录制生效。请将两端更新至最新版本以保持设置同步。

没有真实记录也能体验

在“历史记录”点击“载入演示记录”，进入详情查看曲线、回放与轨迹。演示运动数据为明确标注的合成示例，不是真实测量。

校准与 2D / 3D 轨迹

轨迹需要完整的重力和前进方向校准、有效地理航向，以及当前连续运动数据段内通过质量检查的 GPS。在“曲线范围与校准”保存新的分析范围，会重新计算共享的 2D / 3D 轨迹；恢复完整录制并保存可重算全程，原始采样保留。不满足轨迹条件时仍可记录和查看可用载荷数据，但不提供纯惯性或仅 GPS 轨迹。估算会漂移，佩戴和动作也会影响测量；本工具不提供乘坐安全认证或专业工程测量。

气压高度以本次录制首个有效气压样本为零点，可在 GPS 通过质量检查后辅助高度估计；裁剪分析范围不会重置零点。气压计不能替代 GPS 或地理航向，也不会单独生成轨迹。

自动裁剪乘坐区间

在“曲线范围与校准”点击“自动裁剪：提升 / 弹射至刹车”，生成包含提升或弹射至最终刹车的建议区间。本机记录需先完成 XYZ 校准；识别不依赖 GPS。可微调或恢复全程，保存后更新统计、回放、对比、导出和轨迹。无法可靠识别时保留原选择，请手动调整。四数组导入记录缺少倾斜信息，平稳提升段可能需要手动补选，裁剪也不会生成轨迹。

曲线更平滑，测量值保留

本机载荷曲线会在显示时抑制短促孤立毛刺和高频抖动，保留持续峰值与真实缺测断线。点选读数、回放读数、统计和 CSV / JSON 使用未施加这层显示滤波的测量值，因此可能与显示曲线略有差异。校准页的原始曲线及四数组导入载荷不应用这层显示滤波。

同步与数据保留

Watch 记录通过 WatchConnectivity 传至配对 iPhone。本机记录、配图、Watch 原始文件、收件箱及备注草稿排除系统设备备份；一般设置可能参与系统备份。迁移或重装前，可手动创建不含备注的 iCloud 备份，或通过分享页导出需要保留的记录。记录 JSON 保留备注，配图需另行保存。

Watch 只有在 iPhone 校验并保存记录、返回入库回执后才标记已同步。iPhone 容量不足时，收件箱和 Watch 原件会保留，Watch 仍可离线录制；腾出空间或扩容后，可在同步设置中重试。

记录空间与购买

默认可在 iPhone 保存 50 条记录。在设置 → 留住每一次精彩 → 记录空间，或历史页的“记录空间”查看用量，可一次性购买“100 条记录”将总容量提升到 100 条，或购买“无限记录”解除记录条数上限。两者都是非消耗型商品，不是订阅；价格以 App Store 显示为准。升级为独立购买，按所选商品的完整价格支付，之前的购买不抵扣。扩容不增加 iCloud 空间，也不改变单次 20 分钟或文件大小等限制。

历史页的记录空间入口通常在底部，达到容量的 90% 时移至顶部（45/50 或 90/100 条）。本机所有已保存记录都占用容量，包括演示记录和保留的不可读文件。满额时开始新录制会打开容量购买页；已有记录仍可查看、编辑和导出，也可删除不再需要的记录以释放空间。

在“记录空间”购买页点击“恢复购买”，可恢复当前 App Store 账户的有效容量权益，不会自动恢复记录。最高有效档位生效；退款或权益撤销后回到仍有效的档位或免费 50 条，已有记录保留。iCloud 手动备份与恢复默认免费提供。

购买未解锁、待批准与退款

已购买但未解锁时，请确认 App Store 使用购买时的账户，返回应用或在“记录空间”点击“恢复购买”。iCloud 账户可与 App Store 账户不同；恢复购买只恢复有效容量权益，记录和配图需另行从 iCloud 快照恢复。支付被中断或提示错误时，先核对当前权益，避免重复购买。

等待批准期间尚未解锁新增容量，可以关闭购买页；批准后应用会在收到交易更新时刷新权益。请求被拒绝或过期时，可主动重新检查，再决定是否重试。退款可按 Apple 的退款说明申请，是否获批以 Apple 处理结果为准。退款后的容量按仍有效的最高档位计算，已有记录保留。

应用使用条款见 Apple 标准最终用户许可协议（EULA）；iCloud 服务的数据处理见 Apple 账户与 iCloud 隐私说明。

iCloud 手动备份与恢复

进入设置 → 记录备份，可免费查看、创建和恢复手动快照，无需购买或恢复购买。每次备份均由你主动发起，不自动备份或双向同步；使用你自己的 iCloud 云盘空间，需要登录 iCloud、开启云盘并有足够空间。

新建快照包含已入库至 iPhone 的记录、精确 GPS、气压数据、校准和配图，排除全部备注、设置及未同步的 Watch 文件。本机备注保留，但无法从新快照中恢复。备份后请确认状态为“已上传至 iCloud”；等待系统上传不代表已经完成，迁移设备或卸载前应先确认。

恢复需选择快照并确认，只添加本机缺失且未在本机删除的记录，不覆盖已有编辑。恢复也受当前记录容量限制；剩余容量不足以容纳本次需要新增的记录时，不导入任何新增记录，腾出空间或扩容后可重试。

备份包含全部已入库记录的完整原始采样，不限于当前选中的记录或分析区间；裁剪分析范围不会从快照中移除区间外的 GPS 或其他采样。Watch 记录须先成功同步并保存到 iPhone，才能纳入快照。打开备份页会读取已有快照列表和上传状态，不会创建新快照。

备份或恢复没有完成？

先确认已登录 iCloud 并开启 iCloud 云盘，网络、iCloud 空间和本机存储可用。“等待系统上传”不表示云端已有完整副本，可刷新列表确认状态。若提示快照正在下载，请等待后再次点击恢复；切换 iCloud 账户后，请重新确认列表中的快照。

没有可用记录或本机存在无法读取的记录时，不会创建新快照，原文件保留。每份快照最多 10,000 条记录、256 MiB，单张配图最多 16 MiB；购买无限记录不会移除这些限制。大体积记录可逐条导出 JSON，配图另行保存；完整记录 JSON 当前没有手动导回入口。

记录条数容量不足时，本次恢复不会新增任何记录。通过容量检查后，若磁盘写入中断，已经成功恢复的记录会保留；解决本机存储问题后重试会跳过这些记录，不会重复导入或覆盖已有编辑。

导入载荷 JSON

历史页“导入 JSON”或系统“用 CoasterTool 打开”接受 Vertical、Lateral、Longitudinal、Combined 四数组载荷格式。预览后确认采样率（默认 50 Hz）再保存；文件不带采样率和乘坐日期。导入记录保留原始四通道，可选择范围、回放和对比，但不能重新校准或生成轨迹。完整 CoasterTool 记录 JSON 目前没有手动导回入口；App 内恢复记录与配图请使用 iCloud 快照。

导出与隐私选择

PNG、CSV 和四数组 JSON 不含 GPS 坐标。记录 JSON 包含原始定位、传感器数据、校准及备注。回放配图不包含在这些导出中，需另行保存。

管理记录副本

删除 iPhone 记录及配图不会删除 Watch 原始文件、导出副本或 iCloud 快照，同步成功也不会自动删除 Watch 文件。云端快照可在“文件”App → iCloud 云盘 → CoasterTool → Backups-v1 中管理。卸载会移除对应设备的本机数据和删除标记；重装或换机后仍可手动恢复受支持的旧快照。退款不会删除本机记录或既有快照。

旧版本快照可能包含备注，不会自动改写或删除。恢复受支持的旧快照可取回其中的备注，再次备份会排除备注。你可在“文件”App 中检查并自行删除不再需要的旧快照。

上述系统设备备份排除规则针对当前本机存储，不会追溯清理以前已经创建的系统设备备份，其中可能仍有旧版保存的备注草稿；这些备份需由你通过系统备份管理功能处理。

请遵守设施规定，安全固定设备，并在乘坐前开始录制。乘坐过程中不要操作设备；测量结果不能用于判断乘坐是否安全。
