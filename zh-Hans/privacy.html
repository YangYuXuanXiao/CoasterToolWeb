隐私政策

关于本政策

更新于 2026 年 9 月 28 日，适用于 Coaster Tool 1.1。开发者：Yangyuxuan,Xiao。Coaster Tool 无需注册应用账号，用于乘坐记录与分析，不提供安全评估。可选的购买和云端备份分别使用你的 App Store 与 iCloud 账户。

设备上处理的数据

应用在设备上处理运动数据、设备可用的气压与相对高度、可选 GPS 精确位置、时间、名称、乐园、座位、备注、收藏、设置及选中的照片。仅复制系统照片选择器中选中的图片，移除副本的原始 EXIF/GPS 信息，不修改照片库原件。备注草稿单独保存在排除系统设备备份的本机目录。升级时仅在成功保存后移除旧偏好中的草稿副本；失败会保留原件并提示重试。一般设置及名称、乐园、座位草稿可能参与系统设备备份。

Watch 同步与本地存储

Watch 记录通过 WatchConnectivity 传至配对 iPhone。本机记录、配图、Watch 原始文件、收件箱及备注草稿排除系统设备备份；一般设置可能参与系统备份。迁移或重装前，可手动创建不含备注的 iCloud 备份，或通过分享页导出需要保留的记录。记录 JSON 保留备注，配图需另行保存。

iCloud 手动备份与恢复

iCloud 手动备份与恢复默认免费提供，无需购买或恢复购买。只有你点击“立即备份到 iCloud”时，应用才会把此 iPhone 已入库的记录创建为独立快照，保存至当前 iCloud 账户。购买记录容量、恢复购买或打开页面不会自动上传记录；该功能不进行自动备份或双向同步。

新建快照包含运动原始采样、气压与相对高度、精确 GPS 位置、时间、名称、乐园、座位、四通道载荷、校准结果、分析区间、收藏及配图，并保留记录标识和用于去重的 Watch 来源摘要。全部备注、应用设置、未同步到 iPhone 的 Watch 记录、Watch 原始文件及收件箱均不上传。本机备注保留，但无法从新建快照中恢复。主动导出的记录 JSON 仍包含备注。

备份使用你自己的 iCloud 云盘空间，由 Apple 提供存储与传输服务，开发者无法访问你的 iCloud 云盘。需要登录 iCloud、开启云盘并有可用空间；上传由系统调度，写入本地云盘目录不等于已上传成功。请确认云端状态后再迁移设备或卸载应用。

恢复需由你选择快照并确认。应用只添加本机缺失且未在本机删除的记录，不覆盖已有编辑；不支持或损坏的快照不会导入，云端原文件保留。切换 iCloud 账户会清空可见备份列表，旧操作的结果不会继续写入本机。

恢复仍受本机记录容量限制。若剩余容量不足以容纳本次需要新增的记录，应用不会提交任何新增记录；你可腾出空间或扩容后重试，云端快照保持不变。

备份包含全部已入库记录的完整原始采样，不限于当前选中的记录或分析区间；裁剪分析范围不会从快照中移除区间外的 GPS 或其他采样。Watch 记录须先成功同步并保存到 iPhone，才能纳入快照。打开备份页会读取已有快照列表和上传状态，不会创建新快照。

应用内购买与恢复购买

默认本机容量为 50 条记录，可通过 Apple 应用内购买将总容量提升到 100 条或无限记录。容量商品为一次性非消耗型购买，不是订阅；价格以 App Store 显示为准。各档位独立收费，升级按所选商品的完整价格支付，之前的购买不抵扣。iCloud 备份与恢复免费提供；容量购买不增加 iCloud 空间，也不改变录制时长或文件大小限制。

Apple 处理付款。应用在设备上使用 StoreKit 提供的商品信息、交易标识、商品标识及购买或撤销状态验证容量权益，最高有效档位生效。启动、返回前台和收到交易更新时会核对权益；只有主动点击“恢复购买”才发起恢复购买流程，系统可能要求验证 App Store 账户。此过程不向开发者上传乘坐记录、位置或配图。开发者不接收你的支付卡资料或 Apple 账户密码，也不运行接收交易的服务器。

Apple 另行处理账户、支付及购买数据，并可能向开发者提供不直接识别个人的购买和退款报表。删除应用不会清除 Apple 保留的交易记录。详情见 App Store 与隐私。

可在“记录空间”购买页点击“恢复购买”。容量权益跟随购买所用的 App Store 账户，备份跟随当前 iCloud 账户，两者可以不同。恢复购买不会自动上传记录或恢复备份。退款或权益撤销后回到仍有效的档位或免费 50 条，已有本机记录和云端快照保留；已有记录仍可查看、编辑、导出和删除，新增记录需满足当前容量限制。

应用使用条款见 Apple 标准最终用户许可协议（EULA）；iCloud 服务的数据处理见 Apple 账户与 iCloud 隐私说明。

你控制的导出与分享

PNG、CSV 和四数组 JSON 不含 GPS 坐标。记录 JSON 包含原始定位、传感器数据、校准及备注。回放配图不包含在这些导出中，需另行保存。

分享由你发起，文件交给你选择的应用或接收者，由你管理导出副本。

保留与删除

本机记录保留至你删除。删除 iPhone 记录及配图不会删除 Watch 原始文件、导出副本或 iCloud 快照；同步成功也不会自动删除 Watch 文件。删除对应设备上的 App 会移除其本机数据。

每次手动备份保留独立快照，删除本机记录、关闭 App 或退款均不会删除云端副本。你可在“文件”App → iCloud 云盘 → CoasterTool → Backups-v1 中管理或删除这些快照。旧版本快照可能包含备注，不会自动改写或删除；恢复受支持的旧快照可取回其中的备注，再次备份会排除备注。

为防止迟到的 Watch 传输或恢复操作重新生成已删除记录，本机保留删除标记（记录标识，以及适用时的 Watch 来源摘要）。卸载会移除这些标记，因此在重装后或另一台设备上，旧快照中的记录仍可能被你手动恢复。导出副本由你及你选择的接收者管理。

上述系统设备备份排除规则针对当前本机存储，不会追溯清理以前已经创建的系统设备备份，其中可能仍有旧版保存的备注草稿；这些备份需由你通过系统备份管理功能处理。

权限与撤回

可在系统设置调整运动与定位权限。撤回权限或停止采集不会删除已有副本，可删除对应记录。在前台开始录制并授权定位后，iPhone 锁屏或切换 App 时会继续使用后台定位并显示系统定位指示；Watch 授权定位后也可在后台录制。未授权定位时，两端仍可前台采集，但进入后台会结束并保存。

服务提供方

开发者不运行收集乘坐记录的服务器，应用不含广告、第三方分析 SDK 或跨应用跟踪。Apple 提供 MapKit、App Store 应用内购买和可选的 iCloud 云盘服务，并按其隐私政策处理相关数据。网站由 GitHub Pages 托管，GitHub 可能处理 IP 等请求信息；网站没有分析脚本或追踪 Cookie。Apple 与 GitHub 的隐私声明见下方链接。

网站仅在浏览器本地存储手动选择的语言偏好，用于下次访问；点击“跟随浏览器语言”会清除该偏好。不用于追踪。

联系与更新

隐私问题可通过 GitHub Issues 或电子邮件联系开发者。如涉及 App 使用问题，请在 Issue 或邮件中附上设备型号、系统版本（iOS／watchOS）、App 版本、问题描述、预期与实际结果，以及能够重现问题的具体操作步骤。GitHub Issues 为公开反馈；无论使用哪种方式，请勿附上精确位置、私人照片或原始记录。政策变化会更新日期。
