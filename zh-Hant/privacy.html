隱私政策

關於本政策

更新於 2026 年 9 月 23 日，適用於 Coaster Tool 1.1。開發者：Yangyuxuan,Xiao。Coaster Tool 無須註冊應用程式帳號，用於乘坐記錄與個人身體反應回顧，不提供診斷或安全評估。選用的購買與雲端備份分別使用你的 App Store 與 iCloud 帳號。

裝置上處理的資料

應用程式在裝置上處理運動資料、裝置可用的氣壓與相對高度、可選 GPS 精確位置、時間、名稱、樂園、座位、備註、收藏、設定及選取的照片。僅複製系統照片選擇器中選取的圖片，移除副本的原始 EXIF/GPS 資訊，不修改照片庫原件。備註草稿單獨儲存在排除系統裝置備份的本機目錄。升級時僅在成功儲存後移除舊偏好中的草稿副本；失敗會保留原件並提示重試。一般設定及名稱、樂園、座位草稿可能參與系統裝置備份。

心率與健康資料

心率預設關閉。經健康讀取授權後，應用程式讀取錄製期間可用的心率及時間，用於趨勢、樣本統計與身體反應回顧。不會啟動體能訓練、寫入健康或保證持續取樣。心率不用於廣告、行銷、使用者畫像或研究，不出售健康資料。

Watch 同步與本機儲存

Watch 紀錄（包括已授權擷取的心率）透過 WatchConnectivity 傳送至配對 iPhone。本機紀錄、配圖、Watch 原始檔案、收件匣及備註草稿排除系統裝置備份；一般設定可能參與系統備份。移轉或重新安裝前，可手動建立不含心率和備註的 iCloud 備份，或透過分享頁匯出需要保留的紀錄。紀錄 JSON 保留備註，配圖須另行儲存。

iCloud 手動備份與還原

iCloud 手動備份與還原預設免費提供，無須購買或回復購買。只有你點選「立即備份至 iCloud」時，應用程式才會將此 iPhone 已儲存的紀錄建立為獨立快照，儲存至目前的 iCloud 帳號。購買紀錄容量、回復購買或開啟頁面不會自動上傳紀錄；此功能不進行自動備份或雙向同步。

新建快照包含運動原始取樣、氣壓與相對高度、精確 GPS 位置、時間、名稱、樂園、座位、四通道載荷、校準結果、分析區間、收藏及配圖，並保留紀錄識別碼和用於去重的 Watch 來源摘要。全部備註、應用程式擷取的心率及時間、應用程式設定、未同步到 iPhone 的 Watch 紀錄、Watch 原始檔案及收件匣均不上傳。本機備註保留，但無法從新建快照中還原。主動匯出的紀錄 JSON 仍包含備註。

備份使用你自己的 iCloud 雲碟空間，由 Apple 提供儲存與傳輸服務，開發者無法存取你的 iCloud 雲碟。需要登入 iCloud、開啟雲碟並有可用空間；上傳由系統排程，寫入本機雲碟目錄不等於已成功上傳。請確認雲端狀態後再移轉裝置或解除安裝。

還原須由你選擇快照並確認。應用程式只加入本機缺少且未在本機刪除的記錄，不覆寫現有編輯；不支援或損壞的快照不會匯入，雲端原始檔案會保留。切換 iCloud 帳號會清空可見的備份清單，舊操作的結果不會繼續寫入本機。

還原仍受本機紀錄容量限制。若剩餘容量不足以容納本次需要新增的紀錄，應用程式不會提交任何新增紀錄；你可釋出空間或擴充容量後重試，雲端快照保持不變。

App 內購買與回復購買

預設本機容量為 50 條紀錄，可透過 Apple App 內購買將總容量提升到 100 條或無限紀錄。容量商品為一次性非消耗型購買，並非訂閱；價格以 App Store 顯示為準。各級別獨立收費，升級按所選商品的完整價格付款，先前的購買不折抵。iCloud 備份與還原免費提供；容量購買不增加 iCloud 空間，也不改變錄製時長或檔案大小限制。

Apple 處理付款。應用程式在裝置上使用 StoreKit 提供的商品資訊與經過驗證的交易，確認容量購買或撤銷狀態；最高有效級別生效。開發者不會收到你的支付卡資料，也不會營運接收這些交易或紀錄的伺服器。

可在「記錄空間」購買頁點選「回復購買」。容量權益跟隨購買所用的 App Store 帳號，備份跟隨目前的 iCloud 帳號，兩者可以不同。回復購買不會自動上傳紀錄或還原備份。退款或權益撤銷後回到仍有效的級別或免費 50 條，現有本機紀錄和雲端快照保留；現有紀錄仍可查看、編輯、匯出和刪除，新增紀錄須符合目前容量限制。

你控制的匯出與分享

PNG、CSV 與四陣列 JSON 不含心率或 GPS 座標。記錄 JSON 包含原始定位、感測器資料及備註，預設不含心率。只有在分享頁主動開啟「在 JSON 中包含心率」，本次 JSON 才會帶上心率及時間。關閉該選項會立即撤下舊分享檔案；每次重新開啟分享頁預設關閉。回放配圖不包含在這些匯出中，須另行儲存。

分享由你發起，檔案交給你選擇的應用程式或接收者，由你管理匯出副本。

保留與刪除

本機記錄保留至你刪除。刪除 iPhone 記錄及配圖不會刪除 Watch 原始檔案、匯出副本或 iCloud 快照；同步成功也不會自動刪除 Watch 檔案。刪除對應裝置上的 App 會移除其本機資料。

每次手動備份保留獨立快照，刪除本機紀錄、關閉 App 或退款均不會刪除雲端副本。你可在「檔案」App → iCloud 雲碟 → CoasterTool → Backups-v1 中管理或刪除這些快照。舊版本快照可能包含備註，不會自動改寫或刪除；還原受支援的舊快照可取回其中的備註，再次備份會排除備註。

為防止延遲的 Watch 傳輸或還原操作重新產生已刪除記錄，本機保留刪除標記（記錄識別碼，以及適用時的 Watch 來源摘要）。解除安裝會移除這些標記，因此在重新安裝後或另一台裝置上，舊快照中的記錄仍可能由你手動還原。匯出副本由你及你選擇的接收者管理。

權限與撤回

可在系統設定調整運動、定位權限，在健康 App 或系統健康權限中撤回心率讀取。關閉心率開關僅影響下次錄製；撤權或停止採集不會刪除已有副本，可刪除對應記錄。健康讀取未獲授權時，運動錄製仍可使用。在前景開始錄製並授權定位後，iPhone 鎖定螢幕或切換 App 時會繼續使用背景定位並顯示系統定位指示；Watch 授權定位後也可在背景錄製。未授權定位時，兩端仍可前景採集，但進入背景會結束並儲存。

服務提供者

開發者不會營運用於收集乘坐記錄的伺服器，應用程式不含廣告、第三方分析 SDK 或跨應用程式追蹤。Apple 提供 MapKit、App Store 內購買及選用的 iCloud 雲碟服務，並依其隱私權政策處理相關資料。網站由 GitHub Pages 託管，GitHub 可能處理 IP 等請求資訊；網站沒有分析指令碼或追蹤 Cookie。Apple 與 GitHub 的隱私權聲明見下方連結。

網站僅在瀏覽器本機儲存手動選擇的語言偏好，供下次造訪使用；點選「跟隨瀏覽器語言」會清除此偏好。不用於追蹤。
