隱私政策

關於本政策

更新於 2026 年 9 月 10 日。開發者：Yangyuxuan,Xiao。Coaster Tool 無需應用程式帳號，用於乘坐記錄與個人身體反應回顧，不提供診斷或安全評估。

裝置上處理的資料

應用程式在裝置上處理運動資料、可選 GPS 精確位置、時間、名稱、樂園、座位、備註、收藏、設定及選取的照片。僅複製系統照片選擇器中選取的圖片，移除副本的原始 EXIF/GPS 資訊，不修改照片庫原件。

心率與健康資料

心率預設關閉。經健康讀取授權後，應用程式讀取錄製期間可用的心率及時間，用於趨勢、樣本統計與身體反應回顧。不會啟動體能訓練、寫入健康或保證持續取樣。心率不用於廣告、行銷、使用者畫像或研究，不出售健康資料。

Watch 同步與備份

Watch 記錄（包括已授權採集的心率）透過 WatchConnectivity 傳至配對 iPhone。記錄、配圖、Watch 檔案與收件匣排除系統裝置備份。App 內手動或自動 iCloud 備份上傳非心率資料到個人 CloudKit 私有資料庫。自動備份預設關閉，關閉或切換帳號會停止後續自動備份。

雲端備份包含原始運動與 GPS、校準、分析範圍、記錄資訊及配圖，排除心率及其統計。由於本機記錄目錄排除系統備份，移轉或重新安裝前，請自行備份需要保留的資料。心率不會隨 App 內 iCloud 還原回來。刪除既有雲端資料前請先關閉自動備份。

你控制的匯出與分享

分享由你發起。PNG、CSV 和四陣列 JSON 不含心率或 GPS 座標。感測器記錄 JSON 包含精確定位與備註，預設排除心率；只有明確開啟「在 JSON 中包含心率」後才包含心率。分享內容交給你選擇的應用程式或接收者，由你管理匯出副本。

保留與刪除

本機記錄保留至你刪除；刪除 iPhone 記錄及配圖不會刪除 Watch 原始檔案、雲端版本或匯出副本。同步成功不自動刪除 Watch 檔案。關閉備份不刪除既有雲端資料。為防止延遲同步恢復已刪除記錄，本機保留記錄識別碼與摘要。雲端資料可透過系統 iCloud 儲存空間管理刪除；刪除 Watch App 會移除其本機資料。

權限與撤回

可在系統設定調整運動、定位權限，在健康 App 或系統健康權限中撤回心率讀取。關閉心率開關僅影響下次錄製；撤權或停止採集不會刪除已有副本，可刪除對應記錄。健康讀取未獲授權時，運動錄製仍可使用。拒絕定位仍可前景採集；Watch 在無定位授權時進入背景會結束錄製。

服務提供者

開發者不運行收集乘坐記錄的伺服器，應用程式不含廣告、第三方分析 SDK 或跨應用程式追蹤。MapKit 和 iCloud 由 Apple 提供。網站由 GitHub Pages 託管，GitHub 可能處理 IP 等請求資訊；網站沒有分析指令碼或追蹤 Cookie。Apple 與 GitHub 的隱私聲明可在網頁版政策查看。

聯絡與更新

隱私問題可透過開發者支援頁的 GitHub Issues 聯絡開發者。該入口公開，請勿提交心率、精確位置、私人照片或原始記錄；開發者無法讀取你的個人 CloudKit 資料。政策變更會更新日期。
