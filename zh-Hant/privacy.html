隱私政策

關於本政策

更新於 2026 年 9 月 13 日。開發者：Yangyuxuan,Xiao。Coaster Tool 無需應用程式帳號，用於乘坐記錄與個人身體反應回顧，不提供診斷或安全評估。

裝置上處理的資料

應用程式在裝置上處理運動資料、可選 GPS 精確位置、時間、名稱、樂園、座位、備註、收藏、設定及選取的照片。僅複製系統照片選擇器中選取的圖片，移除副本的原始 EXIF/GPS 資訊，不修改照片庫原件。

心率與健康資料

心率預設關閉。經健康讀取授權後，應用程式讀取錄製期間可用的心率及時間，用於趨勢、樣本統計與身體反應回顧。不會啟動體能訓練、寫入健康或保證持續取樣。心率不用於廣告、行銷、使用者畫像或研究，不出售健康資料。

Watch 同步與本機儲存

Watch 記錄（包括已授權採集的心率）透過 WatchConnectivity 傳至配對 iPhone。App 不再提供 iCloud 備份或還原。本機記錄、配圖、Watch 原始檔案及收件匣排除系統裝置備份。移轉或重新安裝前，請從分享頁匯出需要保留的記錄，並另行儲存配圖。

你控制的匯出與分享

PNG、CSV 與四陣列 JSON 不含心率或 GPS 座標。記錄 JSON 包含原始定位、感測器資料及備註，預設不含心率。只有在分享頁主動開啟「在 JSON 中包含心率」，本次 JSON 才會帶上心率及時間。關閉該選項會立即撤下舊分享檔案；每次重新開啟分享頁預設關閉。回放配圖不包含在這些匯出中，須另行儲存。

分享由你發起，檔案交給你選擇的應用程式或接收者，由你管理匯出副本。

保留與刪除

本機記錄保留至你刪除；刪除 iPhone 記錄及配圖不會刪除 Watch 原始檔案或匯出副本。同步成功不自動刪除 Watch 檔案。為防止延遲同步恢復已刪除記錄，本機保留記錄識別碼與摘要。刪除 Watch App 會移除其本機資料。舊版產生的 iCloud 備份不會隨本次功能移除而刪除。

權限與撤回

可在系統設定調整運動、定位權限，在健康 App 或系統健康權限中撤回心率讀取。關閉心率開關僅影響下次錄製；撤權或停止採集不會刪除已有副本，可刪除對應記錄。健康讀取未獲授權時，運動錄製仍可使用。在前景開始錄製並授權定位後，iPhone 鎖定螢幕或切換 App 時會繼續使用背景定位並顯示系統定位指示；Watch 授權定位後也可在背景錄製。未授權定位時，兩端仍可前景採集，但進入背景會結束並儲存。

服務提供者

開發者不運行收集乘坐記錄的伺服器，應用程式不含廣告、第三方分析 SDK 或跨應用程式追蹤。MapKit 由 Apple 提供。網站由 GitHub Pages 託管，GitHub 可能處理 IP 等請求資訊；網站沒有分析指令碼或追蹤 Cookie。Apple 與 GitHub 的隱私聲明可在網頁版政策查看。

網站僅在瀏覽器本機儲存手動選擇的語言偏好，供下次造訪使用；點選「跟隨瀏覽器語言」會清除此偏好。不用於追蹤。

聯絡與更新

隱私問題可透過開發者支援頁的 GitHub Issues 聯絡開發者。該入口公開，請勿提交心率、精確位置、私人照片或原始記錄。政策變更會更新日期。
