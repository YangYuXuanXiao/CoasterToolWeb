記錄這一程，回看每個瞬間。

Coaster Tool 在 iPhone 與 Apple Watch 記錄過山車運動。可查看載荷曲線、校準、回放、比較及估算的 2D / 3D 軌跡。

需要協助？

請透過 GitHub Issues 提交裝置、系統、App 版本與重現步驟。意見公開，請勿上傳精確位置、私人照片或完整紀錄。

聯絡開發者（公開意見）

開始錄製與鎖定螢幕

運動權限用於錄製，定位可選。在前景開始錄製並授權定位後，iPhone 可在鎖定螢幕或切換 App 後繼續錄製，並顯示系統背景定位指示；Apple Watch 授權定位後也支援背景錄製。未授權定位時，兩端進入背景都會結束並儲存。單次最長 20 分鐘。

背景錄製仍受系統排程影響，可能出現缺測或被終止；iPhone 被強制退出或系統終止時，尚未儲存的錄製可能遺失。缺失取樣不會被補造。

支援 iOS 17 及以上和 watchOS 10 及以上。iPhone 即時三軸顯示未校準的裝置載荷，Watch 顯示原始合載荷；錄製後的列車方向載荷須完成相應校準。裝置可用時還會採集氣壓和相對高度，氣壓計不可用不影響其他感測器錄製。

停止錄製前確認

iPhone 與 Apple Watch 的停止錄製前確認分別設定，預設關閉。開啟後，點選結束錄製需要再次確認；關閉時直接結束。手錶設定也可在 iPhone 的「Apple Watch 設定與同步」頁面修改；離線變更在連線後同步，錄製期間收到的變更於下次錄製生效。請將兩端更新至最新版本以維持設定同步。

合成示範

在歷史頁載入示範紀錄，即可查看曲線、回放與軌跡。示範運動資料為明確標示的合成範例，並非真實測量。

校準與 2D / 3D 軌跡

軌跡需要完整的重力與前進方向校準、有效地理航向，以及目前連續運動資料段內通過品質檢查的 GPS。在「曲線範圍與校準」儲存新的分析範圍，會重新計算共用的 2D / 3D 軌跡；還原完整錄製並儲存可重算全程，原始取樣保留。不符合軌跡條件時仍可錄製和查看可用載荷資料，但不提供純慣性或僅 GPS 軌跡。估算會漂移，佩戴和動作也會影響測量；本工具不提供乘坐安全認證或專業工程測量。

氣壓高度以本次錄製首個有效氣壓樣本為零點，可在 GPS 通過品質檢查後輔助高度估計；裁剪分析範圍不會重設零點。氣壓計不能替代 GPS 或地理航向，也不會單獨產生軌跡。

自動裁剪乘坐區間

在「曲線範圍與校準」點選「自動裁剪：提升 / 彈射至煞車」，產生涵蓋提升或彈射至最終煞車的建議區間。本機紀錄須先完成 XYZ 校準；辨識不依賴 GPS。可微調或恢復全程，儲存後更新統計、回放、比較、匯出及軌跡。無法可靠辨識時保留原選擇，請手動調整。四陣列匯入紀錄缺少傾斜資訊，平穩提升段可能需要手動補選，裁剪也不會產生軌跡。

曲線更平滑，測量值保留

本機載荷曲線會在顯示時抑制短促孤立毛刺與高頻抖動，保留持續峰值及真實缺測斷線。點選讀數、回放讀數、統計與 CSV / JSON 使用未套用這層顯示濾波的測量值，因此可能與顯示曲線略有差異。校準頁的原始曲線及四陣列匯入載荷不套用這層顯示濾波。

同步與資料保留

Watch 紀錄透過 WatchConnectivity 傳送至配對 iPhone。本機紀錄、配圖、Watch 原始檔案、收件匣及備註草稿排除系統裝置備份；一般設定可能參與系統備份。移轉或重新安裝前，可手動建立不含備註的 iCloud 備份，或透過分享頁匯出需要保留的紀錄。紀錄 JSON 保留備註，配圖須另行儲存。

Watch 只有在 iPhone 驗證並儲存紀錄、傳回入庫回執後才標記已同步。iPhone 容量不足時，收件匣和 Watch 原件會保留，Watch 仍可離線錄製；釋出空間或擴充容量後，可在同步設定中重試。

記錄空間與購買

預設可在 iPhone 儲存 50 條紀錄。在設定 → 留住每一次精彩 → 記錄空間，或歷史頁的「記錄空間」查看用量，可一次性購買「100 條紀錄」將總容量提升到 100 條，或購買「無限紀錄」解除紀錄條數上限。兩者都是非消耗型商品，並非訂閱；價格以 App Store 顯示為準。升級為獨立購買，按所選商品的完整價格付款，先前的購買不折抵。擴充容量不增加 iCloud 空間，也不改變單次 20 分鐘或檔案大小等限制。

歷史頁的記錄空間入口通常在底部，達到容量的 90% 時移至頂部（45/50 或 90/100 條）。本機所有已儲存紀錄都占用容量，包括示範紀錄和保留的無法讀取檔案。額滿時開始新錄製會開啟容量購買頁；現有紀錄仍可查看、編輯和匯出，也可刪除不再需要的紀錄以釋出空間。

在「記錄空間」購買頁點選「回復購買」，可回復目前 App Store 帳號的有效容量權益，不會自動還原紀錄。最高有效級別生效；退款或權益撤銷後回到仍有效的級別或免費 50 條，現有紀錄保留。iCloud 手動備份與還原預設免費提供。

購買未解鎖、待批准與退款

已購買但未解鎖時，請確認 App Store 使用購買時的帳號，返回應用程式或在「記錄空間」點選「回復購買」。iCloud 帳號可與 App Store 帳號不同；回復購買只回復有效容量權益，紀錄與配圖須另行從 iCloud 快照還原。付款中斷或顯示錯誤時，先核對目前權益，避免重複購買。

等待批准期間尚未解鎖新增容量，可以關閉購買頁；批准後應用程式會在收到交易更新時重新整理權益。請求遭拒或過期時，可主動重新檢查，再決定是否重試。退款可依 Apple 的退款說明申請，是否獲准以 Apple 處理結果為準。退款後的容量依仍有效的最高級別計算，現有紀錄保留。

應用程式使用條款請見 Apple 標準使用者授權合約（EULA）；iCloud 服務的資料處理請見 Apple 帳號與 iCloud 隱私權說明。

iCloud 手動備份與還原

進入設定 → 記錄備份，可免費查看、建立和還原手動快照，無須購買或回復購買。每次備份均由你主動發起，不自動備份或雙向同步；使用你自己的 iCloud 雲碟空間，需要登入 iCloud、開啟雲碟並有足夠空間。

新建快照包含已儲存至 iPhone 的紀錄、精確 GPS、氣壓資料、校準和配圖，排除全部備註、設定及未同步的 Watch 檔案。本機備註保留，但無法從新快照中還原。備份後請確認狀態為「已上傳至 iCloud」；等待系統上傳不代表已經完成，移轉裝置或解除安裝前應先確認。

還原須選擇快照並確認，只加入本機缺少且未在本機刪除的紀錄，不覆寫現有編輯。還原也受目前紀錄容量限制；剩餘容量不足以容納本次需要新增的紀錄時，不匯入任何新增紀錄，釋出空間或擴充容量後可重試。

備份包含全部已儲存紀錄的完整原始取樣，不限於目前選取的紀錄或分析區間；裁剪分析範圍不會從快照中移除區間外的 GPS 或其他取樣。Watch 紀錄須先成功同步並儲存至 iPhone，才能納入快照。開啟備份頁會讀取既有快照清單與上傳狀態，不會建立新快照。

備份或還原沒有完成？

先確認已登入 iCloud 並開啟 iCloud 雲碟，網路、iCloud 空間與本機儲存可用。「等待系統上傳」不表示雲端已有完整副本，可重新整理清單確認狀態。若提示快照正在下載，請等待後再次點選還原；切換 iCloud 帳號後，請重新確認清單中的快照。

沒有可用紀錄或本機存在無法讀取的紀錄時，不會建立新快照，原始檔案保留。每份快照最多 10,000 條紀錄、256 MiB，單張配圖最多 16 MiB；購買無限紀錄不會移除這些限制。大體積紀錄可逐條匯出 JSON，配圖另行儲存；完整紀錄 JSON 目前沒有手動匯回入口。

紀錄條數容量不足時，本次還原不會新增任何紀錄。通過容量檢查後，若磁碟寫入中斷，已成功還原的紀錄會保留；解決本機儲存問題後重試會跳過這些紀錄，不會重複匯入或覆寫現有編輯。

匯入載荷 JSON

歷史頁「匯入 JSON」或系統「用 CoasterTool 開啟」接受 Vertical、Lateral、Longitudinal、Combined 四陣列載荷格式。預覽後確認取樣率（預設 50 Hz）再儲存；檔案不含取樣率和乘坐日期。匯入紀錄保留原始四通道，可選擇範圍、回放和比較，但不能重新校準或產生軌跡。完整 CoasterTool 紀錄 JSON 目前沒有手動匯回入口；App 內還原紀錄與配圖請使用 iCloud 快照。

匯出與隱私選擇

PNG、CSV 與四陣列 JSON 不含 GPS 座標。紀錄 JSON 包含原始定位、感測器資料、校準及備註。回放配圖不包含在這些匯出中，須另行儲存。

管理紀錄副本

刪除 iPhone 紀錄及配圖不會刪除 Watch 原始檔案、匯出副本或 iCloud 快照，同步成功也不會自動刪除 Watch 檔案。雲端快照可在「檔案」App → iCloud 雲碟 → CoasterTool → Backups-v1 中管理。解除安裝會移除對應裝置的本機資料與刪除標記；重新安裝或換機後仍可手動還原受支援的舊快照。退款不會刪除本機紀錄或既有快照。

舊版本快照可能包含備註，不會自動改寫或刪除。還原受支援的舊快照可取回其中的備註，再次備份會排除備註。你可在「檔案」App 中檢查並自行刪除不再需要的舊快照。

上述系統裝置備份排除規則針對目前的本機儲存，不會追溯清理以前已建立的系統裝置備份，其中可能仍有舊版儲存的備註草稿；這些備份須由你透過系統備份管理功能處理。

請遵守設施規定，安全固定裝置，並在乘坐前開始錄製。乘坐過程中不要操作裝置；測量結果不能用於判斷乘坐是否安全。
