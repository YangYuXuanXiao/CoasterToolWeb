記錄乘坐，回顧身體反應

Coaster Tool 在 iPhone 與 Apple Watch 記錄過山車運動，協助個人回顧心率與身體反應。可查看載荷曲線、校準、回放、比較及估算的 2D / 3D 軌跡。

需要協助？

請透過 GitHub Issues 提交裝置、系統、App 版本與重現步驟。意見公開，請勿上傳心率、精確位置、私人照片或完整記錄。

聯絡開發者（公開意見）

開始錄製與鎖定螢幕

運動權限用於錄製，定位可選。在前景開始錄製並授權定位後，iPhone 可在鎖定螢幕或切換 App 後繼續錄製，並顯示系統背景定位指示；Apple Watch 授權定位後也支援背景錄製。未授權定位時，兩端進入背景都會結束並儲存。單次最長 20 分鐘。

背景錄製仍受系統排程影響，可能出現缺測或被終止；iPhone 被強制退出或系統終止時，尚未儲存的錄製可能遺失。缺失取樣不會被補造。

支援 iOS 17 及以上和 watchOS 10 及以上。iPhone 即時三軸顯示未校準的裝置載荷，Watch 顯示原始合載荷；錄製後的列車方向載荷須完成相應校準。裝置可用時還會採集氣壓和相對高度，氣壓計不可用不影響其他感測器錄製。

停止錄製前確認

iPhone 設定與 Apple Watch 錄製頁的設定中可分別開啟停止錄製前確認，預設關閉。開啟後，點選結束錄製需要再次確認；關閉時直接結束。兩台裝置分別儲存此設定。

心率與身體反應

心率採集預設關閉，iPhone 與 Watch 分別設定。在目前裝置開啟時會申請健康心率讀取權限，採集開關於下次錄製生效。透過 iPhone 遠端開啟 Watch 心率不會在手錶背景彈出授權；請在手錶設定或下次開始錄製時完成授權。結果與詳情顯示分析區間的樣本點、樣本平均、最低與最高樣本及時間。拖動圖表查看實際樣本，在備註記下當時感受。此功能協助個人健康意識，不推斷壓力、興奮程度或安全狀態。備註不包含在新建 iCloud 備份中。

為何沒有樣本？

只讀取健康中可用的樣本，不啟動體能訓練或控制感測器頻率。授權、系統取樣或同步狀況可能使心率缺測；運動錄製仍可使用。不補造連續心率，樣本平均不是全程平均。

可在設定中申請心率讀取權限以重試。請求完成不代表已取得讀取權限；若沒有彈出提示或曾拒絕，請在健康 App 或系統健康權限中檢查 CoasterTool，並在 iPhone 與 Watch 上分別確認。iPhone 本身沒有心率感測器，Watch 同步可能延遲；錄製結束後才寫入健康的樣本不會自動補入。

合成示範

在歷史記錄載入演示記錄，即可查看明確標示為合成的運動、心率與軌跡。演示資料不來自健康，也不寫入健康。

校準與 2D / 3D 軌跡

軌跡需要完整的重力與前進方向校準、有效地理航向，以及目前連續運動資料段內通過品質檢查的 GPS。在「曲線範圍與校準」儲存新的分析範圍，會重新計算共用的 2D / 3D 軌跡；還原完整錄製並儲存可重算全程，原始取樣保留。不符合軌跡條件時仍可錄製和查看可用載荷資料，但不提供純慣性或僅 GPS 軌跡。估算會漂移，佩戴和動作也會影響測量；本工具不提供診斷、異常警報、乘坐安全認證或專業工程測量。

氣壓高度以本次錄製首個有效氣壓樣本為零點，可在 GPS 通過品質檢查後輔助高度估計；裁剪分析範圍不會重設零點。氣壓計不能替代 GPS 或地理航向，也不會單獨產生軌跡。

自動裁剪乘坐區間

在「曲線範圍與校準」點選「自動裁剪：提升 / 彈射至煞車」，產生涵蓋提升或彈射至最終煞車的建議區間。本機記錄須先完成 XYZ 校準；辨識不依賴 GPS。可微調或恢復全程，儲存後更新統計、回放、比較、匯出及軌跡。無法可靠辨識時保留原選擇，請手動調整。四陣列匯入記錄缺少傾斜資訊，平穩提升段可能需要手動補選，裁剪也不會產生軌跡。

曲線更平滑，測量值保留

本機載荷曲線會在顯示時抑制短促孤立毛刺與高頻抖動，保留持續峰值及真實缺測斷線。點選讀數、回放讀數、統計與 CSV / JSON 使用未套用這層顯示濾波的測量值，因此可能與顯示曲線略有差異。校準頁的原始曲線及四陣列匯入載荷不套用這層顯示濾波。

同步與資料保留

Watch 紀錄（包括已授權擷取的心率）透過 WatchConnectivity 傳送至配對 iPhone。本機紀錄、配圖、Watch 原始檔案、收件匣及備註草稿排除系統裝置備份；一般設定可能參與系統備份。移轉或重新安裝前，可手動建立不含心率和備註的 iCloud 備份，或透過分享頁匯出需要保留的紀錄。紀錄 JSON 保留備註，配圖須另行儲存。

Watch 只有在 iPhone 驗證並儲存紀錄、傳回入庫回執後才標記已同步。iPhone 容量不足時，收件匣和 Watch 原件會保留，Watch 仍可離線錄製；釋出空間或擴充容量後，可在同步設定中重試。

記錄空間與購買

預設可在 iPhone 儲存 50 條紀錄。在設定 → 留住每一次精彩 → 記錄空間，或歷史頁的「記錄空間」查看用量，可一次性購買「100 條紀錄」將總容量提升到 100 條，或購買「無限紀錄」解除紀錄條數上限。兩者都是非消耗型商品，並非訂閱；價格以 App Store 顯示為準。升級為獨立購買，按所選商品的完整價格付款，先前的購買不折抵。擴充容量不增加 iCloud 空間，也不改變單次 20 分鐘或檔案大小等限制。

歷史頁的記錄空間入口通常在底部，達到容量的 90% 時移至頂部（45/50 或 90/100 條）。本機所有已儲存紀錄都占用容量，包括示範紀錄和保留的無法讀取檔案。額滿時開始新錄製會開啟容量購買頁；現有紀錄仍可查看、編輯和匯出，也可刪除不再需要的紀錄以釋出空間。

在「記錄空間」購買頁點選「回復購買」，可回復目前 App Store 帳號的有效容量權益，不會自動還原紀錄。最高有效級別生效；退款或權益撤銷後回到仍有效的級別或免費 50 條，現有紀錄保留。iCloud 手動備份與還原預設免費提供。

iCloud 手動備份與還原

進入設定 → 記錄備份，可免費查看、建立和還原手動快照，無須購買或回復購買。每次備份均由你主動發起，不自動備份或雙向同步；使用你自己的 iCloud 雲碟空間，需要登入 iCloud、開啟雲碟並有足夠空間。

新建快照包含已儲存至 iPhone 的紀錄、精確 GPS、氣壓資料、校準和配圖，排除心率、全部備註、設定及未同步的 Watch 檔案。本機備註保留，但無法從新快照中還原。備份後請確認狀態為「已上傳至 iCloud」；等待系統上傳不代表已經完成，移轉裝置或解除安裝前應先確認。

還原須選擇快照並確認，只加入本機缺少且未在本機刪除的紀錄，不覆寫現有編輯。還原也受目前紀錄容量限制；剩餘容量不足以容納本次需要新增的紀錄時，不匯入任何新增紀錄，釋出空間或擴充容量後可重試。

匯入載荷 JSON

歷史頁「匯入 JSON」或系統「用 CoasterTool 開啟」接受 Vertical、Lateral、Longitudinal、Combined 四陣列載荷格式。預覽後確認取樣率（預設 50 Hz）再儲存；檔案不含取樣率和乘坐日期。匯入紀錄保留原始四通道，可選擇範圍、回放和比較，但不能重新校準或產生軌跡。完整 CoasterTool 紀錄 JSON 目前沒有手動匯回入口；App 內還原紀錄與配圖請使用 iCloud 快照。

匯出與隱私選擇

PNG、CSV 與四陣列 JSON 不含心率或 GPS 座標。記錄 JSON 包含原始定位、感測器資料及備註，預設不含心率。只有在分享頁主動開啟「在 JSON 中包含心率」，本次 JSON 才會帶上心率及時間。關閉該選項會立即撤下舊分享檔案；每次重新開啟分享頁預設關閉。回放配圖不包含在這些匯出中，須另行儲存。

管理記錄副本

刪除 iPhone 紀錄及配圖不會刪除 Watch 原始檔案、匯出副本或 iCloud 快照，同步成功也不會自動刪除 Watch 檔案。雲端快照可在「檔案」App → iCloud 雲碟 → CoasterTool → Backups-v1 中管理。解除安裝會移除對應裝置的本機資料與刪除標記；重新安裝或換機後仍可手動還原受支援的舊快照。退款不會刪除本機紀錄或既有快照。

舊版本快照可能包含備註，不會自動改寫或刪除。還原受支援的舊快照可取回其中的備註，再次備份會排除備註。你可在「檔案」App 中檢查並自行刪除不再需要的舊快照。

請遵守設施規定，安全固定裝置，並在乘坐前開始錄製。乘坐過程中不要操作裝置；測量結果不能用於判斷乘坐是否安全。

用於個人健康意識與身體反應回顧，不提供診斷、異常警報或乘坐安全建議。作出醫療決定前請諮詢醫師。
