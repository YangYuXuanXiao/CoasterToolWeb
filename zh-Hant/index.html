記錄乘坐，回顧身體反應

Coaster Tool 在 iPhone 與 Apple Watch 記錄過山車運動，協助個人回顧心率與身體反應。可查看載荷曲線、校準、回放、比較及估算的 2D / 3D 軌跡。

需要協助？

請透過 GitHub Issues 提交裝置、系統、App 版本與重現步驟。意見公開，請勿上傳心率、精確位置、私人照片或完整記錄。

聯絡開發者（公開意見）

開始使用

定位可選，運動權限用於錄製。iPhone 進入背景即結束並保存；Watch 授權定位後可在背景錄製，但系統調度可能造成缺測。最長 20 分鐘。

心率與身體反應

在本裝置設定開啟心率採集，下次錄製時授權健康讀取。結果與詳情顯示分析區間的樣本點、樣本平均、最低與最高樣本及時間。拖動圖表查看實際樣本，在備註記下當時感受。此功能協助個人健康意識，不推斷壓力、興奮程度或安全狀態。

為何沒有樣本？

只讀取健康中可用的樣本，不啟動體能訓練或控制感測器頻率。授權、系統取樣或同步狀況可能使心率缺測；運動錄製仍可使用。不補造連續心率，樣本平均不是全程平均。

合成示範

在歷史記錄載入演示記錄，即可查看明確標示為合成的運動、心率與軌跡。演示資料不來自健康，也不寫入健康。

校準與使用範圍

在曲線範圍與校準頁設定分析範圍和基準。慣性軌跡會漂移，動作和佩戴影響讀數。本工具不提供診斷、異常警報、安全認證或專業工程測量。

備份與分享

Watch 透過系統將含授權心率的記錄傳至配對 iPhone。自動 iCloud 備份預設關閉且排除心率；本機記錄、配圖、Watch 檔案及收件匣排除系統備份。PNG、CSV 與四陣列 JSON 無心率或 GPS。記錄 JSON 含定位與備註，僅在分享頁明確開啟心率選項才包含心率及時間；每次重開分享頁預設關閉。

請遵守設施規定，安全固定裝置，並在乘坐前開始錄製。乘坐過程中不要操作裝置；測量結果不能用於判斷乘坐是否安全。

用於個人健康意識與身體反應回顧，不提供診斷、異常警報或乘坐安全建議。作出醫療決定前請諮詢醫師。
